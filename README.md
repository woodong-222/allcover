# 🎳 allcover

볼링 치고 나서 "누가 얼마 내야 하지?" 계산하는 웹앱.

게임비·신발비·기타 비용에 내기까지 한 번에 정리하고, 결과를 **이미지로 만들어 카카오톡에 바로 공유**합니다.

설치 없이 브라우저에서 바로 씁니다. 폰·태블릿·PC 다 됩니다.

---

## 이렇게 씁니다

1. **참여자 이름**을 넣습니다
2. **게임 단가**와 **신발비**를 넣습니다
3. **판을 추가**하고, 그 판에 누가 쳤는지 고릅니다
4. 결과가 바로 나옵니다 → **공유하기**

내기를 안 했다면 여기까지가 전부입니다.

---

## 내기

판마다 **정산**과 **내기** 중에 고릅니다. 3판은 그냥 치고 4판만 내기했다면, 그렇게 판별로 다르게 설정할 수 있습니다.

내기를 골랐다면 두 가지 방식이 있습니다.

### 판돈 분배 (천바리)

모두 같은 금액을 걸고, 등수에 따라 나눠 갖습니다.

> **5명이 1,000원씩 걸고 1등 3,000원 · 2등 2,000원**
> 1등은 2,000원 이득, 2등은 1,000원 이득, 나머지 3명은 각 1,000원씩 더 냅니다.

등수는 이름을 **탭하는 순서**로 정해집니다. 1등부터 차례로 누르면 되고, 배당이 있는 등수까지만 누르면 나머지는 자동으로 처리됩니다.

승자독식도 같은 방식입니다 — 1등에게 걷은 돈 전부를 몰아주면 됩니다.

### 판비 내주기

진 쪽이 이긴 쪽 몫을 대신 냅니다. 등수를 매길 필요 없이 진 사람만 고르면 됩니다.

> **4:4 팀전, 게임비 4,000원**
> 진 팀 4명이 각자 4,000원씩 더 내고, 이긴 팀은 그 판 게임비가 공짜가 됩니다.

> **8명 중 꼴찌 한 명이 다 내기**
> 꼴찌 혼자 28,000원(7명분)을 부담합니다.

팀전도 됩니다. 팀을 짜두면 진 팀을 한 번에 고를 수 있습니다.

---

## 기타 비용

음료수, 주차비처럼 게임비 외에 나눠 낼 것들입니다.

기본은 **똑같이 나누기**지만, 사람마다 다르게 낼 수도 있습니다.

> 음료수 — 철수는 2,000원짜리, 영희는 2,500원짜리
> "개별 금액 입력"을 켜고 각자 금액을 넣으면 됩니다.

결과 표에는 **항목 이름 그대로** 나옵니다. "기타"가 아니라 "음료수", "주차비"로요.

---

## 알아두면 좋은 것

**금액에 소수점은 나오지 않습니다.** 나누어떨어지지 않으면 전원이 같은 금액이 되도록 1원 단위로 올립니다. 8,000원을 3명이 나누면 2,667원씩입니다. 한 명만 1원 덜 내는 것보다 낫다고 봤습니다. 이때 1~2원 더 걷히는데, 그 사실도 결과에 표시됩니다.

**내 브라우저에만 저장됩니다.** 서버가 없습니다.

- 입력하다 창을 닫아도 다시 열면 그대로 있습니다
- 다른 기기에서는 이어서 볼 수 없습니다
- 브라우저 데이터를 지우면 함께 사라집니다

**공유 방식**은 두 가지입니다. 폰에서 "공유하기"를 누르면 카카오톡 등으로 이미지가 바로 전송되고, PC에서는 이미지 파일로 저장됩니다. 텍스트로 복사해서 붙여넣을 수도 있습니다.

## 직접 실행하기

```bash
npm install
npm run dev
```

Vercel에 배포하려면 저장소를 연결하고 프레임워크를 **Vite**로 두면 됩니다. 나머지 설정은 이미 들어 있습니다.
