# allcover

볼링 모임 정산을 게임비·신발비·내기까지 한 번에 계산하고, 결과를 이미지로 공유하는 웹앱입니다. 서버 없이 브라우저만으로 동작합니다.

## 내기 규칙

allcover의 모든 내기는 **제로섬 이체**입니다. 내기를 하든 안 하든 그날 총 지출액(게임비 + 신발비 + 기타비용)은 똑같고, 내기 결과에 따라 **사람 사이에서 부담이 오갈 뿐**입니다. 판마다 아래 두 방식 중 하나를 고르거나, 내기를 안 할 수도 있습니다.

### 기본 정산 (게임비 · 신발비)

내기와 별개로, 각자 실제로 친 판 수만큼 게임비를 내고 신발을 빌린 사람만 신발비를 냅니다.

> 3명이서 게임비 4,000원, 신발비 2,000원일 때 — A는 4판, B는 3판(+신발 대여), C는 3판을 쳤다면
> A `16,000원`(4×4,000) / B `14,000원`(3×4,000+2,000) / C `12,000원`(3×4,000) → 합계 `42,000원`

### 방식 ① 판돈 분배 (`pot`, 일명 "천바리")

참여자 전원이 인당 판돈(`ante`)을 걷고, 등수별로 정해둔 **인당 배당액**을 나눠 갖습니다. 배당이 없는 등수까지 탭하지 않아도 되고, 탭하지 않은 사람은 전원 동일한 최하위(무배당) 그룹으로 처리됩니다.

- **개인전 5명, 인당 판돈 1,000원, 1등 3,000원 / 2등 2,000원**
  걷은 돈 5,000원 = 나눠준 돈 (3,000+2,000)원 ✓
  1등은 `-2,000원`(더 받음), 2등은 `-1,000원`, 나머지 3명은 각 `+1,000원`(더 냄) → 합 0
- **승자독식, 5명, 인당 판돈 1,000원, 1등 5,000원**
  1등은 `-4,000원`, 나머지 4명은 각 `+1,000원`
- **팀전 4팀 × 2명, 인당 판돈 1,000원, 1등팀 인당 3,000원 / 2등팀 인당 1,000원**
  걷은 돈 8,000원 = 나눠준 돈 (3,000×2 + 1,000×2)원 ✓
  1등팀 두 명 각 `-2,000원` / 2등팀 두 명 각 `0원` / 3·4등팀 네 명 각 `+1,000원`

걷은 돈과 나눠준 돈이 안 맞으면(`imbalance`) 화면에 경고가 뜨고, 계산은 숨기지 않고 그 값 그대로 반영됩니다.

### 방식 ② 판비 내주기 (`transfer`)

등수를 매길 필요 없이 이긴 쪽/진 쪽만 나누면 됩니다. **진 쪽이 이긴 쪽 1인분 금액을 대신 부담**합니다.

- **팀전 4:4, 대신 내주는 금액 4,000원(그날 게임비 그대로)**
  진 팀 4명은 각 `+4,000원`, 이긴 팀 4명은 각 `-4,000원` (진 팀이 이긴 팀 1명분씩 내준 셈)
- **개인전 8명, 꼴찌 1명만 짐, 금액 4,000원**
  꼴찌 혼자 `+28,000원`(7명분을 몰빵), 나머지 7명은 각 `-4,000원`

금액을 "그날 게임비"에 연동해두면 게임비를 나중에 바꿔도 자동으로 반영됩니다.

## 로컬 실행

```bash
npm install       # 의존성 설치
npm run dev       # 개발 서버
npm run test      # 단위 테스트 (vitest)
npm run build     # 타입체크 + 프로덕션 빌드
```

## Vercel 배포

1. 이 저장소를 Vercel에 연결합니다.
2. 프레임워크 프리셋은 **Vite**, Build Command는 `npm run build`, Output Directory는 `dist`로 설정합니다 (Vite 프리셋 선택 시 자동 채워집니다).
3. 새로고침이나 딥링크 접근 시 404가 나지 않도록 `vercel.json`에 SPA rewrite(`/(.*) → /index.html`)가 이미 설정되어 있습니다. 별도 설정이 필요 없습니다.

## 데이터는 어디에 저장되나요

**서버가 없습니다. 모든 데이터는 지금 보고 있는 브라우저의 localStorage에만 저장됩니다.**

- 다른 기기나 다른 브라우저에서는 이어서 볼 수 없습니다 (동기화 없음).
- 브라우저의 사이트 데이터/캐시를 지우면 정산 내역도 함께 사라집니다.
- 시크릿/프라이빗 모드 등 저장이 막힌 환경에서는 화면에 "저장 불가" 안내가 뜨고, 그 세션 동안만 메모리에서 동작합니다(새로고침하면 사라짐).

## 기술 스택

- Vite + React + TypeScript
- Tailwind CSS v4
- Zustand (`persist` 미들웨어로 localStorage 저장)
- html-to-image (결과 카드를 PNG로 캡처)
- nanoid, Vitest

폰트는 별도로 내려받지 않고 시스템 폰트 스택을 씁니다(`src/index.css`). 웹폰트를 self-host하지 않기로 한 이유는, 정산 결과 이미지를 캡처할 때 CDN 폰트가 CORS로 누락되어 한글이 깨지는 문제를 아예 원천 차단하기 위해서입니다. 대신 각 기기의 기본 한글 폰트로 렌더링됩니다.
